# Мониторинг продуктовых метрик

Мониторинг используется для автоматического обнаружения нетипичных изменений ключевых метрик раннего пользовательского пути Flood-It!.

Контролируются три метрики:

- `first_result_reach` — доля новых пользователей, дошедших до первого результата игры;
- `activation_rate` — доля пользователей с первым результатом, достигших критерия активации;
- `d1_retention` — D1 retention среди пользователей, для которых метрика наблюдаема.

## Детектор аномалий

Для каждой метрики текущее дневное значение сравнивается с предыдущими 14 днями.

Baseline рассчитывается как медиана исторических значений.

Разброс оценивается через MAD (Median Absolute Deviation):

`median ± 3 × 1.4826 × MAD`

Аномалия фиксируется только при выполнении дополнительных условий:

- доступно не менее 7 исторических наблюдений;
- знаменатель не меньше 30;
- MAD отличен от нуля.

## Alerting

После построения `mart_product_monitoring` Airflow запускает `check_product_anomalies`.

Если на последнюю доступную дату обнаружена аномалия:

1. задача Airflow остаётся успешной;
2. информация об аномалии записывается в Airflow logs;
3. alert сохраняется в `product_alerts.log`.

Технические ошибки обрабатываются через `on_failure_callback` и записываются в `failure_alerts.jsonl`.

## Workflow при продуктовой аномалии

После получения product alert проводится последовательная диагностика:

1. **Проверка данных**
   - полнота загрузки;
   - корректность событий;
   - отсутствие резкого изменения объёма данных.

2. **Проверка размера когорты**
   - знаменатель метрики;
   - изменение количества новых пользователей.

3. **Сегментация по platform**
   - Android;
   - iOS.

4. **Проверка ранней воронки**
   - new user;
   - first result;
   - activation.

5. **Проверка поведения после первого результата**
   - outcome первого прохождения;
   - retry после первого поражения;
   - same-day return;
   - D1 retention.

6. **Интерпретация**
   - техническая проблема;
   - изменение состава пользователей;
   - локальное изменение одного сегмента;
   - потенциальное изменение продуктового поведения.
